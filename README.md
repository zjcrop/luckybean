# Lucky Bean

Lucky Bean 是一个以咖啡豆管理、冲煮方案匹配、冲煮辅助、品鉴记录与个人风味偏好为核心的咖啡工具项目。

## 当前版本

当前主线版本：1.24B

## 功能概览

- 咖啡豆档案管理与豆卡
- 图片 / OCR / 二维码 / 语音辅助录入
- 冲煮方案自动匹配与手动选择
- BrewProfiles 计算与 3D 风味轨迹兼容
- 冲煮倒计时与语音辅助
- 杯测、快速品鉴与完整品鉴记录
- 器材、滤杯、滤纸、研磨设备与调水方案管理
- 本地优先数据存储、账号同步与回收站机制
- 历史记录、个人风味偏好与咖啡世界功能
