# 富贵盒子 Lucky Bean

本地优先的咖啡豆管理、拾味冲煮辅助与品鉴记录工具。

## 当前唯一版本

- 版本：**0.9.2**
- 在线地址：<https://zjcrop.github.io/BrewIon/luckybean/>
- 源码分支：`main`

`0.9.2` 以统一主线 `0.9.1` 为基线，落实页面居中、荐榜与择豆动画、轨迹配色、滤纸扣减、主观分差滑轮及器设排版。旧 Beta 页面和历史版本分支不再作为维护入口。

## 页面命名

| 导航 | 页面题注 | 功能 |
|---|---|---|
| 藏 | 豆藏 | 豆卡、库存、赏味期和诹吉归档 |
| 拾 | 拾味 | 冲煮方案、萃取轨迹、计时和制作记录 |
| 鉴 | 品鉴 | 感官节点、自动得分、主观分差、札记和往昔记录 |
| 器 | 器设 | 账户、私器、数藏和本物 |

## 数据架构

- BrewIon：公开编码数据和二维码协议；
- Lucky Bean：公开前端、本地数据和完整离线回退；
- brew-profiles：私有冲煮算法，通过服务端 API 调用。

浏览器不会直接读取私有仓库，也不会保存 GitHub Token。未配置服务端 API 时，拾味页面使用公开的浏览器兼容模型，提供一刀流、两段式、三段式、四六法、平底46净化、五段式和固定脉冲等方案。

## 数据库兼容

应用数据库最低结构版本为6。启动时先读取浏览器中现有 IndexedDB 版本，仅在缺少数据表时向上迁移，不执行降级或清空数据。Service Worker 使用 `luckybean-v0.9.2` 缓存，并对同源运行文件采用网络优先策略。

## 本地运行

```bash
python3 -m http.server 8080
```

打开 `http://localhost:8080/`。不要直接使用 `file://`，否则浏览器可能阻止 ES Modules 和数据文件加载。

## 校验

```bash
npm test
npm run check
npm run browser:smoke
```

浏览器冒烟测试需要 Python Playwright 和 Chromium。

## 发布

Lucky Bean 源码维护在本仓库 `main`；在线网页由 BrewIon 仓库的受控发布流程复制到 `BrewIon/luckybean/`，发布前执行单元测试和静态检查。

Android 工程暂时保留，但 APK 工作流仅允许手动触发。Web 版本完成实际使用验收前，不发布新的 APK。

## 当前外部依赖

- BrewIon 公共编码数据远程地址；
- jsQR 1.4.0，用于二维码图片和摄像头扫描；
- qrcodejs 1.0.0，用于生成分享二维码；
- 可选的私有冲煮 API。

## 已知边界

- 真实邮箱/微信注册、跨设备同步和跨用户留言需要独立后端；
- 私有 `brew-profiles` 不能由浏览器直接调用，必须部署服务端适配接口；
- 首次使用二维码识别库且浏览器尚无缓存时需要联网；
- Android 旧测试包不再作为当前交付物。

## 0.9.2 功能基线

- 豆藏与拾味题注基于完整页面宽度居中；
- 豆卡超过6只时按国家分组，分组底部空白区域与“收”均可退出；
- 个人荐榜仅显示魁首、榜眼、探花；
- 择豆模式统一为榜魁、味盛、价冠、拾余、拈签，并使用对应随机提示词；
- 择豆时展开全部分组、滚动定位、轻微颤动并标记目标豆卡；
- 冲煮轨迹采用指定色系，并标记花香、果香、酸、甜、苦、涩的峰值区域；
- “终”会停止计时和语音播报；完成冲煮时同时扣除咖啡豆与所选滤纸1张；
- 品鉴总分节点只录入 -10 至 +10 的主观分差；
- 器设的账户、私器、数藏、本物标题与说明均居中；
- 冲煮记录保存完整方案，可直接复刻；
- 分享继续使用向后兼容的 `LB8` 压缩格式，最多携带最近5条冲煮和5条品鉴。
