# Lucky Bean AI Policy

## Principle

AI is an optional enhancement service. The application must remain functional when AI is disabled or unavailable.

## Current Provider

Zhipu AI integration has been tested and can be used as the current AI enhancement provider.

## AI Tasks

Suitable:
- Natural language tasting analysis
- Copywriting generation
- Optional difficult OCR assistance
- Explanation generation

Unsuitable:
- Core brewing calculation
- Timer control
- Brewing animation control
- Mandatory workflow decisions

## Failure Handling

AI timeout or failure must fall back to local functionality without data loss.
