# Core v2 既有数据设备验收

用于有 schema 10 真实数据的 Android 设备。模拟器的 Golden fixture 不能代替这项验收；只有下表的实际结果齐全，才可关闭 #22。

准备：在旧版“器设 → 数藏”导出备份，记录豆卡、已完成冲煮、品鉴、库存、回收站、自定义代码和照片的数量；使用同一签名的候选 APK 覆盖升级，不能卸载旧版或清除应用数据。

| 操作 | 验收结果 | 实测结果 |
|---|---|---|
| 覆盖升级后启动 | 仍显示既有数据，尚未自动迁移 | 待实测 |
| 数藏确认迁移至 Room | 显示进度；取消可重试；记录数与 SHA-256 校验通过 | 待实测 |
| 切换 GeckoView | 照片与偏好校验后切换；所有照片和本地数据可读 | 待实测 |
| 强制停止并重启 | 仍使用 GeckoView；Room 与照片数据仍在 | 待实测 |
| 飞行模式读写豆卡、完成既有方案 | 保存历史、扣豆账本、outbox；重复保存不重复扣豆 | 待实测 |
| 飞行模式拍摄或选图并 OCR | 中英文本地识别和原图绑定可用 | 待实测 |
| 导出备份到系统文件选择器 | 文件可重新导入，原有字段与私密记录兼容 | 待实测 |
| 扫码与返回键 | 相机权限拒绝可恢复；扫码和应用内返回正常 | 待实测 |
| 冲煮切到后台再返回 | 计时与通知继续，暂停、恢复、取消一致 | 待实测 |
| 切回 WebView，再回滚 IndexedDB | 恢复 Room 最新数据及照片；逐表数量和 SHA-256 一致 | 待实测 |
| 回滚后再次重启 | 旧引擎显示最新编辑、历史、密文、outbox 和照片 | 待实测 |

请在此表记录设备型号、Android 版本、候选 commit SHA、候选 APK SHA-256、日期及各步骤结果。不要把真实品鉴密文、设备密钥、登录令牌或完整数据库上传到 Issue；保留本机备份，用数量与校验结果记录验收。

专业冲煮方案仍来自 BrewProfiles 在线接口。离线验收执行已保存的方案，不将本地参考计算当作专业方案。
