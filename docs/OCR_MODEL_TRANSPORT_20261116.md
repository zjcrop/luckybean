# LuckyBean 1.24P-main.23 / main.23-dsb

修复浏览器 OCR 模型归档请求可能被下载管理器接管，造成识别不可用的问题。模型以 JSON 获取并在内存解码，通过 SHA-256 校验后交给原 PP-OCRv5 SDK；网页不再请求 `.tar` URL。模型版本和识别流程保持一致，Worker 与兼容模式共用此加载方式，初始化成功或失败均释放临时 Blob。

包含上一版水质与实测萃取核算、萃离联动、重复段号和语音缓存修复。两个版本的正式签名 APK 直链和 SHA256 文件已放在 README。

本地校验：云端 363、DS-B 375 项 Node 测试和 37 项静态脚本通过，0 失败、0 跳过。两个真实浏览器 OCR 入口均成功识别测试图，模型 HTTP 请求只有两个 JSON，无 tar 请求、无下载事件。另有模型损坏与初始化失败的内存清理测试。

未在用户实际下载管理器的扩展环境中试用；此修复消除了截图中的归档 URL 请求，无法保证第三方扩展任意配置都不干预网络流量。
