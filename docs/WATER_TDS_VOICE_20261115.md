# 水TDS、实测萃取与计时播报更新（2026-11-15）

本次同步LuckyBean Cloud 1.24P-main.22与DS-B 1.24P-main.22-dsb。Cloud继续使用服务端权威计算，DS-B继续离线本地参考计算。

## 水与咖啡液分开核算

- 原水TDS采用mg/L；预设参考值与明确输入分开。未知保留null，真实零值不回填85或90。
- 不再仅凭TDS按固定比例捏造Ca/Mg/HCO₃，也不以未经杯测校准的ppm系数改变温度、时长、香气评分或EY。
- 萃离导入的明确离子账本可以参与核对，保留加热前计算来源；单次加热后的浓度仍未知，热历史保留在本机。
- 新增“水与本杯实测”面板。杯中咖啡液TDS使用质量百分比，配对实际投粉与饮料产出计算表观回收率；15g粉、210g饮料、1.35%TDS对应18.90%。缺少实测产出时不以注水量或固定吸水率补齐。
- 水TDS笔的电导换算ppm不会直接从咖啡折光TDS中扣除；表观回收率不宣称是已校正的纯咖啡固形物或全浸泡总萃取率。
- 切换豆子或水型清空本杯实测，输入错误清除旧结果；历史快照与统一BrewResult保留诊断。

## 计时文字与语音

阶段显示、准备、开始、自动/手动切换、下一段提示及原生执行使用统一文案。导入名称已有段号时只显示一次，缺少index时按实际数组次序编号；倒计时明确标注“本段剩余”。短阶段不再把开始、提前预告和完整三秒倒数挤在同一时刻。

服务器生成的准备及注水指令同样修正，旧记录的已知系统准备文案保留兼容；器具、冰量、水温、水量及操作提示保留。Android预合成语音缓存按文字及音色、语言、TTS引擎、语速和音调生成身份，避免新文案继续复用旧录音。
