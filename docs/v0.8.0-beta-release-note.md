# Lucky Bean v0.8.0-beta.1 发布说明

本版本只部署到独立Beta目录，不替换v0.7.0稳定版，不构建APK。

## 关键变化

- 紧凑豆卡、超过6只自动分组、田字快捷区；
- 拾味兼容模型覆盖7类冲煮法，专业内容默认折叠；
- Brew-Water-Calibrato v2.7咖啡水参数兼容；
- 方案JSON/TXT/Markdown导出；
- 退/驻/进/终计时控制；
- 自动得分、主观得分、札记、偏好标签和荐榜；
- 低分问题诊断、修正方案、历史方案复刻；
- `LB8`压缩分享协议，包含最近冲煮与品鉴。

## 技术边界

浏览器不能安全读取私有GitHub仓库。Beta内置的是公开的浏览器兼容模型；私有 `brew-profiles` 的精确算法继续通过可选服务端API接入，未复制进公开仓库。
