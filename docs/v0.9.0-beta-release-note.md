# 富贵盒子 v0.9.0-beta.1 发布说明

## 基线与边界

本版本以富贵盒子 `v0.8.0-beta.1` 源码为唯一产品基线。上传的独立计算工具仅作为冲煮计算模型的参考来源；未修改该上传文件，也未把其页面、IndexedDB、导航或表单结构替换进富贵盒子。

稳定版 `v0.7.0` 继续保留在 `BrewIon/luckybean/`。本版本只发布到独立 Beta 路径 `BrewIon/luckybean-beta/`，使用独立版本号和 Service Worker 缓存。

## 冲煮模型

- 将品种敏感度、温度响应、流速、水质、目标萃取率和风味轨迹整理为纯计算模块 `src/brew-model-v09.js`；
- 保留富贵盒子的拾味页面、数据结构和记录/复刻机制；
- 轨迹图显示温度、流量、累计注水、花香、酸、甜、口感与苦涩风险，并标注阶段窗口；
- 方案支持模型推荐、一刀流、两段式、三段式、四六法、平底 46 净化、五段式和 30g/15s 脉冲；
- 首段/尾段降温支持模型推荐与手工修订；
- 计时器在阶段切换前播报下一段克重、水温、方法、降温幅度和注意事项。

## 豆藏与数据修复

- 修正产区和庄园中文字段索引；
- 旧代码先归一化再显示，失效代码不再生成空标签；
- 风味标签按中文分组展示；
- 推荐操作会展开目标分组并标记豆卡；点兵点将按约 667ms/次逐张豆卡运行；
- 分组自动展开/收起 0.2s，手动操作 0.5s；
- 豆卡增加十阶段赏味进度线；详情曲线标注今天、当前状态和升降趋势。

## 品鉴与器设

- 品鉴节点、标题和选项改为居中大触控排版；
- 缺陷、焦苦、药感、橡胶、霉味、干涩等负面项权重显著高于正面标签；
- 器设增加结构化滤纸和滤杯管理；
- 冲煮记录会同步扣减所选滤纸 1 张；
- 滤纸低于 10 张时，“器”显示红色星号，并自动定位到红色加粗库存项；
- 器设折叠区保持单开。

## 验证

- Node 单元测试：21/21 通过；
- 静态检查：JS、JSON、必要入口、重复 ID 和敏感信息检查通过；
- 390×844 Chromium 浏览器流程：豆藏、分组、推荐、豆卡详情、拾味、轨迹图、计时、消耗、品鉴、复刻、分享、器具库存全部通过；
- 浏览器测试无 page error 和 console error。
