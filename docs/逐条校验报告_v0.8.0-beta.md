### 私有引擎边界

`zjcrop/brew-profiles` 是私有仓库。将其精确构件直接放入公开 GitHub Pages 会使源码对所有访问者可读。因此 Beta 没有静默复制私有实现，而是：

1. 按其公开调用契约和产品功能实现浏览器兼容模型；
2. 保留私有服务端 API 调用；
3. API 不可用时完整降级，不再退化为极简方案；
4. 前端不保存 GitHub Token，不访问私有 GitHub API。

- 安卓与iOS真机语音授权和连续听写；

- 修正方案在不同豆种和烘焙批次上的实际感官效果。
